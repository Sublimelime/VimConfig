This is a backup/versioning of my .vim directory, to allow me to quickly backup and use my config on other machines, etc. Feel free to use any of the files in this repo for your own vim config.

External programs needed:

- Ripgrep
- fd
- Neovide if on windows (powershell terminal sucks)
- npm & node
- LLVM(clang) and VS build tools (C++ development on windows) or equivalent for linux

NPM global installs:

npm install -g tree-sitter-cli @vtsls/language-server@0.3.0 @vue/language-server@3.3.7 neovim@5.4.0 basedpyright typescript-language-server@5.3.0 typescript@6.0.3 @tailwindcss/language-server@0.16.0
